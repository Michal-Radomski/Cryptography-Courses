PGP (Pretty Good Privacy) keys are cryptographic key pairs used primarily to encrypt, decrypt, and digitally sign data,
files, and emails to ensure confidentiality and authenticity.

While PGP, OpenSSL, and SSH keys all rely on public-key cryptography (using a public and private key pair), they are designed
for completely different use cases, protocols, and trust models.

| Feature                 | PGP Keys                                                                    | OpenSSL Keys                                                                                       | SSH Keys                                                                        |
| ----------------------- | --------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| **Primary Purpose**     | Encrypting and signing arbitrary files, text, and emails.                   | Managing cryptographic certificates and keys for secure web traffic and general crypto operations. | Authenticating users to remote servers and services (like GitHub or cloud VMs). |
| **Trust Model**         | Decentralized "Web of Trust" where users vouch for each other's keys.       | Centralized Certificate Authorities (CAs) or self-signed certificates.                             | Direct authorization via server-side configuration (`authorized_keys`).         |
| **Typical File Format** | ASCII-armored blocks starting with `-----BEGIN PGP PUBLIC KEY BLOCK-----`.  | PEM or DER formats, often encapsulated in X.509 certificates (`.pem`, `.crt`, `.key`).             | OpenSSH public key format (e.g., starting with `ssh-ed25519` or `ssh-rsa`).     |
| **Core Use Case**       | Secure communication between individuals and software package verification. | Securing web browsers (HTTPS/TLS) and application-level encryption.                                | Passwordless command-line login and remote administration.                      |

### Key Characteristics

- **PGP (GnuPG):** Binds a user's identity (such as a name and email address) directly to the key via digital signatures. It
  is built for end-to-end data security rather than network authentication.
- **OpenSSL:** A robust toolkit that handles the Public Key Infrastructure (PKI) powering the web. It creates the keys and
  certificates that web servers use to establish HTTPS connections with browsers.
- **SSH:** Highly specialized for network protocol authentication. An SSH key pair proves to a server that you are who you
  say you are, allowing you to run shell commands remotely without transmitting a password.
