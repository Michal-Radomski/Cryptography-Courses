Base58 is a binary-to-text encoding format designed to translate raw computer data into clean, human-readable strings while
eliminating visually confusing characters. It is used in Bitcoin primarily to prevent costly user errors when reading,
typing, or sharing cryptocurrency addresses.

**Character Set Design** Base58 uses a custom alphabet consisting of 58 alphanumeric characters. Crucially, it deliberately
excludes characters that look identical or very similar in many fonts, as well as non-alphanumeric symbols:

- `0` (zero) and `O` (capital letter O)
- `I` (capital letter i) and `l` (lowercase letter L)
- Punctuation marks like `+` and `/` (which are present in Base64)

**Why Bitcoin Chooses Base58 Over Base64** While Base64 is more efficient for packing data into standard web protocols, it
fails in user-facing financial applications where errors have permanent consequences.

- **Preventing Irreversible Mistakes:** Cryptocurrency transactions cannot be reversed or refunded. If a user manually types
  an address and mistakes a capital `O` for a zero (`0`), the funds are sent to an invalid or unintended destination forever.
  Base58 removes these lookalikes.
- **Seamless Text Selection:** Base64 relies on symbols like `+` and `/`. When you double-click text in a terminal or web
  browser, punctuation often breaks the selection boundaries, causing you to copy only half the address. Base58's pure
  alphanumeric structure lets users double-click and copy an entire Bitcoin address in one go.
- **Cleaner QR Code Compatibility:** Alphanumeric QR codes can store Base58 data efficiently without getting tripped up by
  erratic punctuation symbols, ensuring faster and more reliable scans on mobile wallets.
