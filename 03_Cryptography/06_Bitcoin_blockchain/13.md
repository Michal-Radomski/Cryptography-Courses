The Ethereum blockchain is a decentralized, open-source platform that features smart contract functionality. While Bitcoin
was created primarily to function as digital money and a store of value (like digital gold), Ethereum was designed as a
programmable global computer. It allows developers to build decentralized applications (dApps), issue custom tokens, and run
self-executing code without relying on a central authority.

| Feature                 | Bitcoin                                           | Ethereum                                        |
| ----------------------- | ------------------------------------------------- | ----------------------------------------------- |
| **Primary Purpose**     | Digital currency and store of value               | Decentralized applications and smart contracts  |
| **Native Coin**         | Bitcoin (BTC)                                     | Ether (ETH)                                     |
| **Programmability**     | Limited scripting language (intentionally simple) | Turing-complete programming language (Solidity) |
| **Consensus Mechanism** | Proof of Work (PoW)                               | Proof of Stake (PoS)                            |
| **Block Time**          | Roughly 10 minutes                                | Roughly 12 seconds                              |

### Key Differences Explained

- **Smart Contracts & Utility:** Bitcoin's scripting language handles basic transaction rules, but Ethereum introduces smart
  contracts—programs that execute automatically when pre-set conditions are met. This capability powers decentralized finance
  (DeFi), non-fungible tokens (NFTs), and entire ecosystems of other applications.
- **Consensus Mechanism:** Bitcoin relies on Proof of Work, requiring miners to solve intense mathematical puzzles using
  massive amounts of electricity to secure the network. Ethereum uses Proof of Stake, where validators lock up (stake) their
  Ether to help secure the network and verify transactions, making it much more energy-efficient.
- **Transaction Speed:** Ethereum blocks are processed in about 12 seconds compared to Bitcoin's 10-minute block intervals,
  allowing for much faster transaction settlement times.
- **Supply Design:** Bitcoin has a hard cap of 21 million coins that will ever exist, emphasizing scarcity. Ethereum does not
  have a hard cap on its total supply; instead, its issuance adjusts dynamically based on network usage and a mechanism that
  burns a portion of transaction fees.
