A Peer-to-Peer (P2P) network is a decentralized communications model where each computer or device (called a "peer") on the
network has equal capabilities and responsibilities, eliminating the need for a powerful central server.

**How P2P Differs from Client-Server Models**

- **Client-Server Architecture:** Traditional web applications rely on a central server that stores all data and processes
  all requests. If the central server goes down or gets overwhelmed by traffic, the service becomes unavailable.
- **P2P Architecture:** Every node in a P2P network acts as both a client (requesting data) and a server (sharing data)
  simultaneously. Participants directly connect with one another to share files, processing power, or information.

**Key Types of P2P Networks**

- **Unstructured P2P:** Nodes are connected randomly. It is easy for peers to join or leave, but finding a specific file can
  require broadcasting search queries across the entire network, which consumes significant bandwidth.
- **Structured P2P:** Uses a rigid underlying mathematical structure—such as a Distributed Hash Table (DHT)—allowing nodes to
  efficiently locate files or data even on massive, global networks without flooding every connection.
- **Hybrid P2P:** Combines elements of both models by using a central server to maintain a directory or index of what files
  are available, while the actual data transfer happens directly peer-to-peer.

**Core Advantages**

- **Resilience and Fault Tolerance:** Because there is no single point of failure, the network continues to function smoothly
  even if thousands of nodes drop offline simultaneously.
- **High Scalability:** As more users join a P2P network, its overall capacity, storage space, and download speeds actually
  increase because each new user brings additional resources.
- **Censorship Resistance:** The decentralized nature means no single government, corporation, or authority can easily block,
  control, or shut down the network.

**Real-World Applications**

- **Cryptocurrencies and Blockchains:** Networks like Bitcoin rely completely on P2P architecture so that global users can
  validate and record transactions together without needing a central bank.
- **File Sharing:** Protocols like BitTorrent use P2P to split large files into tiny fragments, allowing users to download
  pieces from dozens of different people at the same time.
