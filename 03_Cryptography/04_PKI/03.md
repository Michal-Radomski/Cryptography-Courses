## Where Root Certificates are Stored

Operating systems maintain a certificate store containing trusted root certificates (from Certificate Authorities) to verify
secure connections. Here is where you can find them on Ubuntu and Windows:

---

### 1. Ubuntu (Linux)

On Ubuntu and other Debian-based Linux distributions, system-wide trusted root certificates are managed centrally and stored
in the filesystem:

- **Directory Path:** `/usr/share/ca-certificates/` (for available certificates) and `/etc/ssl/certs/` (for active system
  certificates).
- **Bundle File:** Many applications read from a single bundle file located at `/etc/ssl/certs/ca-certificates.crt`.
- **Managing Certificates:** Ubuntu uses the `update-ca-certificates` command to automatically update and link certificates
  in the system store. You can also view or manage user-specific certificates in your browser's certificate manager or user
  directories (e.g., `~/.pki/nssdb`).

---

### 2. Windows

Windows manages root certificates through the Windows Certificate Store, which can be viewed using built-in graphical tools:

- **Graphical Tool (certlm.msc):** Press **Win + R**, type `certlm.msc` (Certificate Manager for Local Computer), and press
  Enter. Navigate to **Trusted Root Certification Authorities > Certificates** to see the full list of installed root
  certificates.
- **Registry Path:** System-wide certificates are stored in the Windows Registry under:
  `HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\SystemCertificates` (or the `Policies` equivalent for group policies).
- **PowerShell:** You can also list them via PowerShell using the command:

```powershell
Get-ChildItem -Path Cert:\LocalMachine\Root

```
