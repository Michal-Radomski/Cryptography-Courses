On Ubuntu, SSL/TLS certificates and private keys are typically stored within the `/etc/ssl/` directory structure, following
standard Linux directory conventions:

- **Public Certificates:** Store public certificate files (such as `.crt`, `.cer`, or `.pem` files) in:

```bash
/etc/ssl/certs/

```

- **Private Keys:** Store private key files (such as `.key` or `.pem` files) in:

```bash
/etc/ssl/private/

```

_Note: Ensure strict file permissions on the private keys directory (`chmod 700` and restricted ownership) so only root or
authorized services can read them._

- **Automated Certificates (Let's Encrypt / Certbot):** If you are using Certbot to manage free certificates, they are
  automatically organized and stored in:

```bash
/etc/letsencrypt/live/your-domain-name/

```
