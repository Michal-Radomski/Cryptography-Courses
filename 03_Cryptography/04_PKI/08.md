Apache HTTP Server primarily accepts **PEM (Privacy-Enhanced Mail)** format for SSL/TLS certificates and private keys, but it
can also support **DER (binary)** formats with proper conversion.

### Accepted Formats

- **PEM (.pem, .crt, .cer, .key):** The standard format used by Apache. These are Base64-encoded ASCII files wrapped between
  header and footer lines (such as `-----BEGIN CERTIFICATE-----`).
- **DER (.der, .cer):** The binary equivalent of PEM. Apache cannot natively parse raw binary DER files for configuration
  unless they are converted into PEM format first using OpenSSL.

### Configuring Different Formats in Apache

To configure certificates in Apache, you specify the paths inside your virtual host configuration file (usually located in
`/etc/apache2/sites-available/` on Ubuntu).

#### 1. Standard PEM Configuration

This is the most common configuration where your certificate, private key, and intermediate chain are in PEM format.

```apache
<VirtualHost *:443>
    ServerName example.com

    SSLEngine on

    # Path to your primary public certificate (.crt or .pem)
    SSLCertificateFile /etc/ssl/certs/example.crt

    # Path to your private key (.key or .pem)
    SSLCertificateKeyFile /etc/ssl/private/example.key

    # Path to the intermediate certificate chain (CA bundle)
    SSLCertificateChainFile /etc/ssl/certs/intermediate.crt
</VirtualHost>

```

#### 2. Using a Combined PEM File (Fullchain)

Modern Apache versions (2.4.8 and newer) allow you to combine your public certificate and the intermediate certificate chain
into a single file using the `SSLCertificateFile` directive, omitting `SSLCertificateChainFile`.

```apache
<VirtualHost *:443>
    ServerName example.com

    SSLEngine on
    SSLCertificateFile /etc/ssl/certs/fullchain.pem
    SSLCertificateKeyFile /etc/ssl/private/privkey.pem
</VirtualHost>

```

#### 3. Converting DER to PEM

If you obtained a certificate in binary DER format and need to use it in Apache, convert it to PEM using OpenSSL from your
terminal before updating your configuration:

- **Convert a DER certificate to PEM:**

```bash
openssl x509 -inform der -in certificate.der -out certificate.crt

```

- **Convert a DER private key to PEM:**

```bash
openssl rsa -inform der -in privatekey.der -out privatekey.key

```
