AES-GCM (Galois/Counter Mode) is the gold standard for modern **Authenticated Encryption with Associated Data (AEAD)**. It
solves a critical weakness found in older modes by providing **both confidentiality** (keeping data secret) and
**integrity/authenticity** (proving the data hasn't been tampered with) at the same time.

### How GCM Works

- **Counter (CTR) Mode Encryption:** It uses CTR mode to encrypt the plaintext by combining it with a keystream, which allows
  for fast, parallelizable encryption and decryption across multiple processor cores.
- **Galois Message Authentication Code (GMAC):** It runs the ciphertext and any additional unencrypted header data
  (associated data) through a universal hash function over a Galois field to generate a cryptographic **authentication tag**.

### Why GCM is Crucial

In traditional modes like CBC or CTR, an attacker who intercepts ciphertext can flip bits to alter the resulting plaintext in
predictable ways without the system knowing. GCM prevents this entirely. If _even a single bit_ of the ciphertext or its
associated metadata is modified in transit, the authentication tag verification fails, and the system immediately rejects the
message rather than processing corrupted or malicious data.

### Common Use Cases

- **HTTPS and TLS 1.3:** Securing the vast majority of web traffic on the modern internet.
- **Secure Storage:** Encrypting files or databases where you must verify that stored data has not been tampered with.
- **Secure Messaging & VPNs:** Protecting data packets as they move across public networks.
