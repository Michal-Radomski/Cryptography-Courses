A padding oracle attack is a cryptographic attack that exploits how a web application or system handles padding errors during
the decryption of block ciphers (most commonly CBC mode).

### How It Works

When a system decrypts a CBC-mode ciphertext, it first reverses the encryption math, removes the PKCS#7 padding, and checks
if the padding is valid.

- **The Oracle:** If the padding is incorrect, the server throws a specific error or behaves differently (e.g., returning a
  "Bad Padding" error or taking a different amount of time to respond). This behavior acts as an "oracle" that leaks
  information.
- **The Exploit:** An attacker can intercept the ciphertext and systematically alter the bytes of the previous block before
  sending it to the server. By observing whether the server accepts or rejects the modified padding, the attacker can
  mathematically deduce the plaintext byte-by-byte without ever knowing the secret encryption key.

### Why It Matters

This vulnerability demonstrates why encryption alone does not guarantee security. Even if an attacker cannot crack the AES
key, they can completely compromise confidentiality if the application leaks error messages about padding validation. Modern
authenticated encryption modes like **GCM** prevent padding oracle attacks entirely because they verify the integrity and
authenticity of the data before attempting any decryption or padding removal.
