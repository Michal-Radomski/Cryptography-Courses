Encryption modes (or modes of operation) are algorithms that define how a block cipher (like AES or DES) processes data
longer than a single block size, ensuring that identical blocks of plaintext do not result in identical ciphertext blocks and
preventing pattern leakage.

### Key Encryption Modes

- **ECB (Electronic Codebook):** The simplest mode where each block of plaintext is encrypted independently using the same
  key. _Drawback:_ Identical plaintext blocks yield identical ciphertext blocks, which leaks structural patterns in the data
  (famously demonstrated by encrypting an image where the outline remains visible). It is insecure for most practical
  applications.
- **CBC (Cipher Block Chaining):** Each block of plaintext is XORed with the previous ciphertext block before being
  encrypted. This creates a chain reaction where every block depends on all preceding blocks. It requires a unique,
  unpredictable Initialization Vector (IV) for the first block to ensure randomness.
- **CTR (Counter Mode):** Turns a block cipher into a stream cipher by encrypting an incrementing counter value to generate a
  key stream, which is then XORed with the plaintext. It is highly efficient because encryption and decryption can be fully
  parallelized across multiple processor cores.
- **GCM (Galois/Counter Mode):** A mode that combines CTR-style encryption with a Galois message authentication code,
  providing **authenticated encryption with associated data (AEAD)**. It simultaneously encrypts the data and generates a
  cryptographic tag to verify its integrity and authenticity, preventing tampering. This is the dominant mode used in modern
  web security.

### Mode Comparison

| Mode    | Parallel Encryption? | Parallel Decryption? | Provides Authentication? | Common Use Cases                                          |
| ------- | -------------------- | -------------------- | ------------------------ | --------------------------------------------------------- |
| **ECB** | Yes                  | Yes                  | No                       | Legacy systems, single-block operations (not recommended) |
| **CBC** | No                   | Yes                  | No                       | File encryption, legacy protocols                         |
| **CTR** | Yes                  | Yes                  | No                       | Disk encryption, high-speed networks                      |
| **GCM** | Yes                  | Yes                  | Yes (AEAD)               | HTTPS, TLS 1.3, AES-GCM secure storage                    |
