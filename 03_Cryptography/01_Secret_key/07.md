To encrypt a file using OpenSSL with a specific cipher mode, key, and Initialization Vector (IV), use the `openssl enc`
command with the `-K` (key) and `-iv` flags provided in hexadecimal format.

### OpenSSL Encryption Command

```bash
openssl enc -<mode-and-cipher> -e -in <input_file> -out <output_file> -K <hex_key> -iv <hex_iv>

```

### Example: Encrypting with AES-256-CBC

To encrypt a file named `secret.txt` using AES-256 in CBC mode with a specific 256-bit key and 128-bit IV (both represented
in hex):

```bash
openssl enc -aes-256-cbc -e -in secret.txt -out secret.enc \
  -K 0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef \
  -iv fedcba9876543210fedcba9876543210

```

### Parameter Breakdown

- **`-<mode-and-cipher>`**: Specifies the cipher and mode (e.g., `-aes-256-cbc`, `-aes-128-gcm`, `-aes-256-ctr`).
- **`-e`**: Explicitly specifies encryption (this is the default behavior, but it helps clarity).
- **`-in`**: The path to the plaintext file you want to encrypt.
- **`-out`**: The path where the resulting ciphertext will be saved.
- **`-K`**: The encryption key expressed as a **hexadecimal string**. (Note the uppercase `K`). The length must match the
  requirement of the chosen cipher (e.g., 64 hex characters for a 256-bit key).
- **`-iv`**: The Initialization Vector expressed as a **hexadecimal string**. The length must match the block cipher's block
  size (e.g., 32 hex characters for AES).

_To decrypt the file later, swap `-e` for `-d` and keep the exact same cipher, key, and IV:_

```bash
openssl enc -aes-256-cbc -d -in secret.enc -out decrypted.txt \
  -K 0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef \
  -iv fedcba9876543210fedcba9876543210

```
