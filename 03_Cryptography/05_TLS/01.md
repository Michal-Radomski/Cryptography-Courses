Transport Layer Security (TLS) is a cryptographic protocol designed to provide secure communications over a computer network,
serving as the backbone for HTTPS, secure email, and other encrypted data transfers. It ensures privacy and data integrity
between two communicating applications.

### Core Objectives of TLS

- **Encryption:** Scrambles data so that third parties cannot read it while it travels across the network.
- **Authentication:** Verifies the identity of the communicating parties (usually confirming to the user that they are
  connected to the actual website they intended to visit, utilizing the PKI system discussed previously).
- **Integrity:** Ensures that data cannot be modified or tampered with during transmission without detection.

### The TLS Handshake Process

Before any actual application data is sent, the client (such as a web browser) and the server go through a "handshake" to
establish a secure connection:

1. **Client Hello:** The client initiates the connection by sending supported cryptographic algorithms (cipher suites), the
   TLS version it supports, and a random number.
2. **Server Hello & Certificate:** The server responds with its chosen cipher suite, its digital certificate (containing its
   public key), and its own random number.
3. **Authentication & Key Exchange:** The client verifies the server's certificate against trusted Certificate Authorities
   (CAs). The client and server then use cryptographic key exchange algorithms (like Diffie-Hellman) to securely agree on a
   shared secret "session key" without transmitting the key itself across the network.
4. **Finished:** Both sides exchange messages confirming that the handshake is complete and encryption is now active. All
   subsequent communication is encrypted using the established session keys.

### Evolution and Versions

- **TLS 1.0 and 1.1:** Older versions that have been deprecated and disabled across modern browsers due to known
  cryptographic vulnerabilities.
- **TLS 1.2:** A widely adopted, secure version that has been the industry standard for many years.
- **TLS 1.3:** The latest major version, finalized in RFC 8446. It significantly improves security by removing outdated and
  insecure cryptographic primitives and reduces handshake latency to a single round-trip (1-RTT) or zero round-trip (0-RTT)
  for faster, more secure connections.
