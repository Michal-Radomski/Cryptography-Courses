The RSA encryption algorithm relies on fundamental concepts in number theory, specifically the asymmetry between the ease of
multiplying large prime numbers and the extreme difficulty of factoring their product.

### Key Mathematical Concepts

1. **Prime Numbers** RSA begins by selecting two distinct, large prime numbers, $p$ and $q$. These primes are kept strictly
   secret.
2. **The Modulus ($n$)** The product of the two primes gives the modulus $n$:

$$n = p \times q$$

The value $n$ is made public and forms part of both the public and private keys. Its bit-length defines the size of the key
(e.g., a 2048-bit RSA key). 3. **Euler's Totient Function ($\phi(n)$)** Euler's totient function, denoted as $\phi(n)$,
counts the positive integers up to $n$ that are relatively prime (coprime) to $n$. For a modulus formed by two distinct
primes $p$ and $q$, the totient is calculated as:

$$\phi(n) = (p - 1)(q - 1)$$

This value is kept secret because knowing $\phi(n)$ makes it trivial to break the private key. 4. **The Public Exponent
($e$)** An integer $e$ is chosen such that it satisfies two conditions:

- $1 < e < \phi(n)$
- $\gcd(e, \phi(n)) = 1$ (i.e., $e$ and $\phi(n)$ are coprime)

The pair $(e, n)$ forms the public key. Commonly, the prime number $65537$ is chosen for $e$ because it provides a good
balance between security and fast computation. 5. **The Private Exponent ($d$)** The private key $d$ is the modular
multiplicative inverse of $e$ modulo $\phi(n)$. It is calculated using the Extended Euclidean Algorithm so that:

$$d \cdot e \equiv 1 \pmod{\phi(n)}$$

The pair $(d, n)$ forms the private key.

---

### Encryption and Decryption Operations

- **Encryption:** To encrypt a plaintext message $m$ (represented as an integer) using the public key $(e, n)$, compute the
  ciphertext $c$:

$$c = m^e \pmod n$$

- **Decryption:** To decrypt the ciphertext $c$ back into the original message $m$ using the private key $(d, n)$, compute:

$$m = c^d \pmod n$$

### Underlying Security Problem

The security of RSA relies on the **Integer Factorization Problem**. An eavesdropper has access to the public key $(e, n)$,
meaning they know $n$. To find the private key $d$, they would need to calculate $\phi(n)$, which requires knowing $p$ and
$q$. For sufficiently large numbers $p$ and $q$ (such as 1024-bit primes yielding a 2048-bit modulus $n$), factoring $n$ back
into $p$ and $q$ is computationally infeasible with classical computing methods.
