The modulo operator possesses several fundamental algebraic properties that allow large calculations to be simplified by
reducing numbers at each step without changing the final remainder.

### Core Algebraic Properties

For any integers $a$, $b$, and a positive modulus $n$:

1. **Addition Property**

$$(a + b) \pmod n = [(a \pmod n) + (b \pmod n)] \pmod n$$

_You can take the modulo of each number before adding, then apply the modulo again to the sum._ 2. **Subtraction Property**

$$(a - b) \pmod n = [(a \pmod n) - (b \pmod n)] \pmod n$$

_Similar to addition, intermediate values can be reduced before subtracting (if the result is negative in programming
languages, you may need to add $n$ to wrap it back into a positive range)._ 3. **Multiplication Property**

$$(a \times b) \pmod n = [(a \pmod n) \times (b \pmod n)] \pmod n$$

_Products can be reduced modulo $n$ at any stage of a multiplication chain._ 4. **Exponentiation Property**

$$(a^b) \pmod n = [(a \pmod n)^b] \pmod n$$

_The base can be reduced modulo $n$ before applying an exponent._

---

### Practical Significance

These properties are the backbone of both computer science and cryptography:

- **Preventing Overflow:** In programming, calculating huge numbers (like $2^{1000}$) directly causes integer overflow
  errors. By applying the modulo operator at each step of a multiplication or addition loop, computers keep numbers small and
  manageable.
- **Modular Exponentiation:** Algorithms like RSA and Diffie-Hellman rely on computing massive powers (e.g., $g^a \pmod p$).
  Using the properties above, algorithms use methods like _square-and-multiply_ to compute these efficiently without ever
  generating astronomically large numbers in memory.
