Here is a simple, step-by-step numeric example using small numbers to show how RSA signing and verification work.

---

## 1. Key Generation (Setup)

- **Choose two prime numbers:** Let $p = 3$ and $q = 11$.
- **Calculate modulus ($n$):**

$$n = p \times q = 3 \times 11 = 33$$

- **Calculate totient ($\phi$):**

$$\phi(n) = (p - 1) \times (q - 1) = (2) \times (10) = 20$$

- **Choose public exponent ($e$):** Let's choose $e = 3$ (since it shares no factors with 20).
- **Calculate private exponent ($d$):** We need a number $d$ where $(d \times e) \pmod{\phi(n)} = 1$, meaning
  $(d \times 3) \pmod{20} = 1$.
- If $d = 7$, then $7 \times 3 = 21$, and $21 \pmod{20} = 1$. So, $d = 7$.

**The Keys:**

- **Public Key (for verifying):** $e = 3$, $n = 33$
- **Private Key (for signing):** $d = 7$, $n = 33$

---

## 2. The Signing Process

Imagine the message digest (hash) is a simple number: **$h = 5$** (which must be less than $n$).

- **Formula:** $s = h^d \pmod n$
- **Calculation:** $s = 5^7 \pmod{33}$
- $5^7 = 78,125$
- $78,125 \div 33 = 2,367$ with a remainder of **$14$**

- **Digital Signature ($s$):** **$14$**

The sender sends the message along with the signature **14**.

---

## 3. The Verification Process

The recipient receives the message hash ($h = 5$) and the signature ($s = 14$). They use the public key ($e = 3, n = 33$) to
check it:

- **Formula:** $h' = s^e \pmod n$
- **Calculation:** $h' = 14^3 \pmod{33}$
- $14^3 = 2,744$
- $2,744 \div 33 = 83$ with a remainder of **$5$**

- **Result ($h'$):** **$5$**

Because the decrypted hash ($h' = 5$) matches the original message hash ($h = 5$), the recipient knows the signature is
authentic and valid!
