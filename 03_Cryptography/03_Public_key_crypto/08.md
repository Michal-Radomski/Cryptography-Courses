RSA padding is essential for security because it adds randomness and strict formatting to a message before encryption,
preventing critical vulnerabilities inherent in raw (textbook) RSA.

Without padding, standard RSA exposes several major weaknesses:

- **Eliminates Determinism:** Textbook RSA is deterministic, meaning encrypting the exact same message always produces the
  exact same ciphertext. If an attacker knows you are sending either a "YES" or "NO" message, they can pre-compute both
  ciphertexts and instantly crack your communication. Padding injects random data (salt) so that encrypting the same message
  twice results in completely different ciphertexts.
- **Prevents Mathematical Exploits (Low-Exponent Attacks):** If a message is very short and the public exponent $e$ is small
  (like 3), the value $m^e$ might actually be less than the modulus $n$. When this happens, no modular wrapping occurs, and
  an attacker can easily read the plaintext just by taking the $e$-th root of the ciphertext. Padding inflates the message
  size so it fills the modulus space.
- **Thwarts Chosen-Ciphertext Attacks (CCA):** Modern padding schemes like OAEP (Optimal Asymmetric Encryption Padding) add
  structure that allows the decryption algorithm to verify if the message was tampered with in transit. If an attacker
  modifies the ciphertext, the padding check fails, and the system rejects it immediately rather than leaking partial data.

In short, raw RSA is a math function, but padded RSA is a secure cryptographic system.
