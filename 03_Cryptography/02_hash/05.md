`cmp` (short for compare) is a standard Linux/Ubuntu command-line utility used to compare two files **byte by byte**.

Unlike text-based comparison tools like `diff` (which compare files line by line and show text additions or deletions), `cmp`
is designed for any file type—including raw binaries, compiled executables, images, and encrypted files—making it especially
useful in scripting and cryptographic verification.

### Common Behaviors & Exit Codes

- **Identical Files:** If the files are completely identical, `cmp` produces **no output** and returns an exit status of `0`.
- **Different Files:** If a difference is found, it reports the exact byte number and line number where the files diverge.

### Common Use Cases and Examples

1. **Basic Comparison:**

```bash
cmp file1.bin file2.bin

```

_Output if different:_ `file1.bin file2.bin differ: byte 45, line 3` 2. **Silent Check in Bash Scripts (`-s`):** The `-s`
(silent) flag suppresses all console output and relies solely on the exit code. This is ideal for `if` statements in shell
scripts:

```bash
if cmp -s original.enc decrypted.txt; then
    echo "Files are identical!"
else
    echo "Files differ!"
fi

```

3. **List All Differences (`-l`):** The `-l` (verbose) flag outputs every differing byte position along with the
   octal/decimal value of the differing bytes in both files:

```bash
cmp -l file1.bin file2.bin

```
