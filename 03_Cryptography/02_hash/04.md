`xxd` is a standard command-line utility in Ubuntu and other Linux systems used to create a hexadecimal representation (hex
dump) of a file or standard input, or to convert a hex dump back into its original binary form.

### Common Use Cases

- **Inspecting Binary Files:** Viewing the raw byte structure of compiled programs, images, or custom data formats.
- **Debugging:** Checking exact byte values, file headers, or hidden characters in text files.
- **Reversing Hex Dumps:** Converting a hex text file back into a binary file.

### Common Commands

1. **View a file as a standard hex dump (Hex + ASCII):**

```bash
xxd filename.bin

```

_This outputs the memory offset on the left, 16 hex bytes in the middle, and the printable ASCII representation on the
right._ 2. **Output a continuous plain hex string (useful for scripts):**

```bash
xxd -p filename.bin

```

3. **Reverse a hex dump back into a binary file (`-r`):**

```bash
xxd -r -p input.hex output.bin

```
