**HMAC (Hash-based Message Authentication Code)** is a specific type of message authentication code that combines a
cryptographic hash function (such as SHA-256) with a secret cryptographic key. It is used to simultaneously verify both the
data integrity and the authenticity of a message, ensuring that the data hasn't been altered in transit and that it genuinely
came from someone who knows the secret key.

---

### Implementing HMAC in Node.js with TypeScript

Node.js provides a built-in `crypto` module that supports HMAC out of the box without requiring external dependencies.

#### Step 1: Ensure Type Definitions

If you are using TypeScript in a standard Node.js project, install the Node types if you haven't already:

```bash
npm install --save-dev @types/node

```

#### Step 2: Write the TypeScript Code

Create a file named `hmacDemo.ts` and use the following implementation:

```typescript
import * as crypto from "crypto";

/**
 * Generates an HMAC SHA-256 signature for a given message.
 * @param secretKey - The shared secret key
 * @param message - The data to authenticate
 * @returns The hexadecimal HMAC digest
 */
function createHmacSignature(secretKey: string, message: string): string {
  return crypto.createHmac("sha256", secretKey).update(message).digest("hex");
}

/**
 * Verifies an incoming HMAC signature securely (preventing timing attacks).
 */
function verifyHmacSignature(secretKey: string, message: string, receivedSignature: string): boolean {
  const computedSignature = createHmacSignature(secretKey, message);

  // Convert strings to buffers for timing-safe comparison
  const computedBuffer = Buffer.from(computedSignature, "hex");
  const receivedBuffer = Buffer.from(receivedSignature, "hex");

  if (computedBuffer.length !== receivedBuffer.length) {
    return false;
  }

  return crypto.timingSafeEqual(computedBuffer, receivedBuffer);
}

// --- Example Usage ---
const secret = "super-secret-shared-key-123";
const messagePayload = "user_id=42&action=transfer";

// 1. Sender generates signature
const signature = createHmacSignature(secret, messagePayload);
console.log(`Generated HMAC: ${signature}`);

// 2. Receiver verifies signature
const isValid = verifyHmacSignature(secret, messagePayload, signature);
console.log(`Is signature valid? ${isValid}`);
```

#### Step 3: Run the TypeScript File

You can use `ts-node` to execute TypeScript files directly in development:

```bash
npx ts-node hmacDemo.ts

```
