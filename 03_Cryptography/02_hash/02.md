**MD (Message Digest)** and **SHA (Secure Hash Algorithm)** are two major families of cryptographic hash functions used to
turn data of any size into a fixed-length digital fingerprint (hash).

---

### 1. The MD (Message Digest) Family

Designed by Ronald Rivest in the early 1990s, the MD family includes algorithms like MD2, MD4, and the most famous—**MD5**.

- **Output Size:** 128 bits (usually represented as a 32-character hexadecimal string).
- **History & Status:** MD5 was widely used for checking file integrity (checksums) and basic data verification. However, it
  is **cryptographically broken and insecure**. Researchers discovered severe vulnerabilities allowing for "collision
  attacks" (where two completely different inputs produce the exact same hash).
- **Current Use:** Only used for non-security-critical tasks, such as checking if a large downloaded file is uncorrupted
  (where malicious tampering isn't a concern). Never use it for passwords or security.

---

### 2. The SHA (Secure Hash Algorithm) Family

Developed by the National Security Agency (NSA) and published by NIST, the SHA family is the standard for secure hashing. It
has evolved through several generations to fix weaknesses found in older versions.

- **SHA-1:**
- _Output Size:_ 160 bits (40 hex characters).
- _Status:_ Deprecated and broken. In 2017, researchers successfully executed the first practical collision attack against it
  (the "SHAttered" attack). It should no longer be used for security.

- **SHA-2:**
- _Output Sizes:_ Commonly **SHA-256** or **SHA-512** (the number indicates the bit length).
- _Status:_ Highly secure and widely trusted. SHA-256 is the current industry workhorse powering HTTPS/TLS, digital
  certificates, and blockchain technology (like Bitcoin). No practical attacks have ever broken it.

- **SHA-3:**
- _Output Sizes:_ Variable lengths matching SHA-2 options.
- _Status:_ The newest standard (selected via a NIST competition in 2015). It uses a fundamentally different internal
  structure (sponge construction) compared to SHA-2, providing an alternative defense-in-depth option.

---

### Quick Comparison

| Algorithm Family | Typical Output Size | Security Status            | Primary Modern Use Cases                             |
| ---------------- | ------------------- | -------------------------- | ---------------------------------------------------- |
| **MD5**          | 128 bits            | Broken / Insecure          | Non-critical checksums only                          |
| **SHA-1**        | 160 bits            | Broken / Deprecated        | Legacy systems (phase out immediately)               |
| **SHA-2**        | 256 or 512 bits     | Secure (Industry Standard) | TLS/HTTPS, digital signatures, software verification |
| **SHA-3**        | Variable            | Secure (Future-proof)      | Modern applications requiring algorithmic diversity  |
