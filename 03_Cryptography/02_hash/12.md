Verifying incoming API webhooks using HMAC ensures that requests genuinely originate from a trusted service provider (like
Stripe, GitHub, or Shopify) rather than a malicious actor.

### Express.js TypeScript Webhook Verification Example

The following implementation uses Express and Node.js's built-in `crypto` module to intercept a webhook request, extract its
signature from the headers, and verify it safely.

#### Step 1: Install Dependencies

Make sure you have Express and TypeScript types installed:

```bash
npm install express
npm install --save-dev @types/express @types/node

```

#### Step 2: Implement the Webhook Verification Middleware

Create a file named `webhookServer.ts`:

```typescript
import express, { Request, Response, NextFunction } from "express";
import * as crypto from "crypto";

const app = express();

// IMPORTANT: Webhook signature verification requires the RAW request body
// (as a Buffer or string), not a parsed JSON object.
// We use express.raw() specifically for the webhook route.
app.use("/api/webhook", express.raw({ type: "application/json" }));

const WEBHOOK_SECRET = "your-provider-shared-secret-key";

/**
 * Middleware to verify the HMAC SHA-256 signature sent in webhook headers.
 */
function verifyWebhookSignature(req: Request, res: Response, next: NextFunction): void {
  // Providers typically send the signature in a custom header (e.g., 'x-signature')
  const signatureHeader = req.headers["x-signature"];

  if (!signatureHeader || typeof signatureHeader !== "string") {
    res.status(401).json({ error: "Missing or invalid signature header" });
    return;
  }

  try {
    // req.body is a Buffer because of express.raw()
    const rawBody = req.body;

    // Compute the expected HMAC using the secret key and the raw payload body
    const computedHmac = crypto.createHmac("sha256", WEBHOOK_SECRET).update(rawBody).digest("hex");

    // Prepare buffers for constant-time comparison to prevent timing attacks
    const computedBuffer = Buffer.from(computedHmac, "hex");
    const receivedBuffer = Buffer.from(signatureHeader, "hex");

    if (computedBuffer.length !== receivedBuffer.length || !crypto.timingSafeEqual(computedBuffer, receivedBuffer)) {
      res.status(401).json({ error: "Signature mismatch" });
      return;
    }

    // Signature is valid! Parse the body to JSON for downstream handlers
    req.body = JSON.parse(rawBody.toString("utf8"));
    next();
  } catch (error) {
    res.status(400).json({ error: "Invalid request body or signature format" });
  }
}

// Webhook endpoint
app.post("/api/webhook", verifyWebhookSignature, (req: Request, res: Response) => {
  const event = req.body;

  console.log("Verified webhook event received:", event.type);

  // Process the verified event data safely here...
  res.status(200).json({ received: true });
});

app.listen(3000, () => {
  console.log("Webhook server running on port 3000");
});
```

### Key Security Practices in This Code

- **Raw Body Handling:** Webhook signatures are calculated over the exact raw byte stream of the HTTP request body. If your
  framework parses JSON automatically before verification, whitespace changes or key ordering differences will cause the
  signature check to fail.
- **Timing-Safe Comparison:** Using `crypto.timingSafeEqual()` prevents timing attacks, ensuring an attacker cannot deduce
  how many bytes of their forged signature matched by measuring response times.
