Cryptography algorithms are generally grouped into three main categories based on their purpose and how they use keys:
**Symmetric Encryption**, **Asymmetric Encryption**, and **Cryptographic Hash Functions**.

---

### 1. Symmetric Encryption Algorithms

Symmetric algorithms use a **single secret key** for both locking (encrypting) and unlocking (decrypting) data. Because they
are fast and efficient, they are used to secure large amounts of data.

- **AES (Advanced Encryption Standard):** The current global industry standard for symmetric encryption. It uses block sizes
  of 128 bits with key lengths of 128, 192, or 256 bits. AES is trusted to secure everything from government files to
  everyday HTTPS web traffic.
- **ChaCha20:** A modern, high-speed stream cipher often paired with Poly1305 for authentication. It is frequently used as an
  alternative to AES on mobile devices or hardware lacking specialized AES acceleration.

---

### 2. Asymmetric Encryption Algorithms

Asymmetric algorithms use a **mathematically linked key pair**: a public key to encrypt data and a private key to decrypt it.
This solves the problem of how to securely share keys over an open network.

- **RSA (Rivest–Shamir–Adleman):** One of the oldest and most widely used asymmetric algorithms. Its security relies on the
  extreme difficulty of factoring massive prime numbers. It is heavily used for secure key exchanges and digital signatures.
- **ECC (Elliptic Curve Cryptography):** A modern asymmetric approach based on the algebraic structure of elliptic curves.
  ECC achieves the same level of security as RSA using much smaller keys, making it faster and more resource-efficient
  (commonly used in smartphones and modern TLS 1.3 connections).

---

### 3. Cryptographic Hash Functions

Hash functions are **one-way mathematical operations** that turn any amount of data into a fixed-size string of characters (a
hash). They cannot be reversed to reveal the original input, making them essential for data integrity and password storage.

- **SHA-256 (Secure Hash Algorithm 256-bit):** Part of the SHA-2 family, it generates a unique 256-bit signature for a file
  or message. Even a tiny change to the input completely alters the resulting hash. It is widely used in digital
  certificates, software verification, and blockchain technology.
- **SHA-3:** The latest member of the Secure Hash Algorithm family, designed by NIST as a robust alternative with a
  completely different internal structure from SHA-2 to provide extra security protection.
