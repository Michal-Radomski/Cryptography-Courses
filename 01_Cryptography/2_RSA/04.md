## How RSA Key Generation Works

RSA key generation is the foundational step in asymmetric cryptography. It creates the mathematically linked public and
private key pair. While libraries handle the heavy math automatically behind the scenes, understanding the underlying steps
clarifies how the keys are born.

---

### The Mathematical Steps (Conceptual)

1. **Choose Two Distinct Prime Numbers:** Select two large, random prime numbers, let's call them $p$ and $q$.
2. **Compute the Modulus ($n$):** Multiply $p$ and $q$ together:

$$n = p \times q$$

The number $n$ is used as the modulus for both the public and private keys. Its length (in bits) is what we refer to as the
"key size" (e.g., 2048-bit or 4096-bit). 3. **Compute Euler's Totient ($\phi$):** Calculate $\phi(n) = (p - 1)(q - 1)$. 4.
**Choose the Public Exponent ($e$):** Select an integer $e$ such that $1 < e < \phi(n)$ and $e$ is coprime to $\phi(n)$
(commonly, $65537$ is chosen for performance and security). The pair $(n, e)$ forms the **Public Key**. 5. **Compute the
Private Exponent ($d$):** Calculate $d$ as the modular multiplicative inverse of $e$ modulo $\phi(n)$ (satisfying
$d \times e \equiv 1 \pmod{\phi(n)}$). The pair $(n, d)$ forms the **Private Key**.

---

### Generating Keys Programmatically in Node.js

As we saw in previous examples, Node.js makes generating these massive prime numbers and computing keys straightforward using
the `crypto` module:

```javascript
const crypto = require("crypto");

// Generate an RSA key pair programmatically
const { publicKey, privateKey } = crypto.generateKeyPairSync("rsa", {
  modulusLength: 2048, // Recommended minimum length for security
  publicKeyEncoding: {
    type: "spki", // SubjectPublicKeyInfo (standard format)
    format: "pem", // Base64 encoded text format
  },
  privateKeyEncoding: {
    type: "pkcs8", // Private Key Syntax Specification
    format: "pem",
  },
});

console.log("--- Public Key ---");
console.log(publicKey);

console.log("\n--- Private Key ---");
console.log(privateKey);
```

---

### Key Length Considerations

- **2048-bit:** Currently considered the industry standard for secure web traffic and digital signatures, offering a good
  balance between security and performance.
- **4096-bit:** Provides higher security for long-term data protection, though it requires more CPU power for encryption,
  decryption, and key generation.
