## Implementing Elliptic Curve Cryptography (ECC) in Node.js

Node.js handles Elliptic Curve Cryptography natively using the built-in `crypto` module, much like it handles RSA. Instead of
choosing a modulus length, you specify a **named curve** (such as `secp256k1` or `prime256v1`).

Here is how you can generate an ECC key pair and use it to create and verify a digital signature:

```javascript
const crypto = require("crypto");

// 1. Generate an ECC Key Pair using a standard curve (e.g., prime256v1 / secp256r1)
const { publicKey, privateKey } = crypto.generateKeyPairSync("ec", {
  namedCurve: "prime256v1",
  publicKeyEncoding: {
    type: "spki",
    format: "pem",
  },
  privateKeyEncoding: {
    type: "pkcs8",
    format: "pem",
  },
});

const message = "Secure transaction data via ECC!";
console.log("Original Message:", message);

// 2. Create a digital signature using the Private Key
const signer = crypto.createSign("SHA256");
signer.update(message);
signer.end();

const signature = signer.sign(privateKey, "base64");
console.log("\nECC Digital Signature (Base64):", signature);

// 3. Verify the signature using the Public Key
const verifier = crypto.createVerify("SHA256");
verifier.update(message);
verifier.end();

const isVerified = verifier.verify(publicKey, signature, "base64");
console.log("\nECC Signature Verified Successfully?", isVerified);
```

### Advantages of ECC Code Implementation:

- **Smaller Footprint:** The resulting keys and signatures are significantly smaller in byte size compared to RSA keys of
  equivalent security strength.
- **Performance:** Operations like signing and verification run faster with lower resource utilization, which is why ECC
  powers modern protocols like TLS 1.3.
