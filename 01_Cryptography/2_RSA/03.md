Here is how you can use RSA to create and verify a **digital signature** in Node.js.

Digital signatures are used to prove that a message or piece of software actually came from the holder of the private key and
that it hasn't been tampered with along the way.

```javascript
const crypto = require("crypto");

// 1. Generate an RSA Key Pair
const { publicKey, privateKey } = crypto.generateKeyPairSync("rsa", {
  modulusLength: 2048,
  publicKeyEncoding: { type: "spki", format: "pem" },
  privateKeyEncoding: { type: "pkcs8", format: "pem" },
});

const documentText = "Contract terms: Party A agrees to pay Party B...";
console.log("Original Document:", documentText);

// 2. Create a digital signature using the PRIVATE key
const signer = crypto.createSign("SHA256");
signer.update(documentText);
signer.end();

const signature = signer.sign(privateKey, "base64");
console.log("\nDigital Signature (Base64):", signature);

// 3. Verify the signature using the PUBLIC key
const verifier = crypto.createVerify("SHA256");
verifier.update(documentText);
verifier.end();

const isVerified = verifier.verify(publicKey, signature, "base64");
console.log("\nSignature Verified Successfully?", isVerified);

// --- Example of Tampering ---
// If the document changes slightly, verification fails:
const tamperedDocument = "Contract terms: Party A agrees to pay Party C...";
const tamperedVerifier = crypto.createVerify("SHA256");
tamperedVerifier.update(tamperedDocument);
tamperedVerifier.end();

const isTamperedVerified = tamperedVerifier.verify(publicKey, signature, "base64");
console.log("Tampered Document Verified?", isTamperedVerified); // Returns false
```

### How Digital Signatures Work:

- **Signing:** The sender hashes the document and encrypts that hash using their **private key**. Because only they have the
  private key, the signature acts as a tamper-proof seal.
- **Verification:** Anyone can use the sender's **public key** to decrypt the signature back into the original hash and
  compare it against a freshly calculated hash of the received document. If they match, the signature is authentic.
