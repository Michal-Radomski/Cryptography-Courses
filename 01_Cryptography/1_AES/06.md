## AES Modes of Operation

Because the Advanced Encryption Standard (AES) is a **block cipher** that only processes data in fixed 128-bit (16-byte)
chunks, **modes of operation** are required to define how it handles data larger than a single block or how it provides
additional security features like data integrity.

---

### Common AES Modes

- **CBC (Cipher Block Chaining):**
- _How it works:_ Each block of plaintext is XORed with the previous ciphertext block before being encrypted. The first block
  uses an Initialization Vector (IV).
- _Use case:_ Widely used in legacy systems, file encryption, and secure communications, though it requires padding for
  non-block-sized data.

- **GCM (Galois/Counter Mode):**
- _How it works:_ Combines a counter mode for encryption with a Galois field multiplication step for authentication. It turns
  AES into an **Authenticated Encryption with Associated Data (AEAD)** scheme.
- _Use case:_ The industry standard for modern web security (TLS/HTTPS, Node.js crypto, secure APIs) because it protects
  against both eavesdropping _and_ tampering.

- **CTR (Counter Mode):**
- _How it works:_ Turns the block cipher into a stream cipher by encrypting a sequential counter value to generate a key
  stream, which is then XORed with the plaintext.
- _Use case:_ Great for high-speed applications or random-access storage encryption since blocks can be encrypted/decrypted
  in parallel.

- **ECB (Electronic Codebook):**
- _How it works:_ Encrypts each 128-bit block independently using the exact same key.
- _Security Note:_ **Insecure for most applications.** Identical plaintext blocks produce identical ciphertext blocks,
  meaning patterns in data (like images) remain visible.
