## The Main Rounds of AES

In the Advanced Encryption Standard (AES) algorithm, the main rounds are where the heavy lifting of encryption takes place.
Depending on your key size, these rounds are repeated multiple times (10 times for AES-128, 12 times for AES-192, and 14
times for AES-256).

Each standard round transforms the 16-byte data block (represented as a 4x4 matrix called the **State**) by applying four
sequential operations:

- **1. SubBytes (Substitution):**
- _What it does:_ Every single byte in the 4x4 State matrix is independently replaced with a new byte using a fixed lookup
  table called the **S-Box** (Substitution Box).
- _Purpose:_ This provides **confusion**, ensuring there is a complex, non-linear relationship between the ciphertext and the
  key.

- **2. ShiftRows (Permutation):**
- _What it does:_ The rows of the State matrix are shifted cyclically to the left by different offsets:
- Row 0: Shifted by 0 bytes (remains unchanged)
- Row 1: Shifted by 1 byte to the left
- Row 2: Shifted by 2 bytes to the left
- Row 3: Shifted by 3 bytes to the left

- _Purpose:_ This ensures that bytes in each column are spread out across different columns, providing **diffusion**.

- **3. MixColumns (Mixing):**
- _What it does:_ Each column of the State matrix is multiplied by a fixed polynomial matrix using finite field arithmetic
  (Galois Field math).
- _Purpose:_ This blends the four bytes of each column together, ensuring that a change in a single input byte affects
  multiple output bytes. _(Note: This step is skipped entirely in the final round of AES)._

- **4. AddRoundKey (Key Mixing):**
- _What it does:_ The current State matrix is combined with the specific **round key** for that round using a bitwise **XOR**
  operation.
- _Purpose:_ This integrates the secret key material directly into the data path, making the encryption unique to that
  specific key.

---

### What Happens After the Main Rounds?

Once all main rounds are completed, the algorithm executes a **Final Round** which follows the exact same steps except for
one omission—it skips the `MixColumns` step, ending with `SubBytes` $\rightarrow$ `ShiftRows` $\rightarrow$ `AddRoundKey`.
