## Overview of the AES Algorithm

The **Advanced Encryption Standard (AES)** is a symmetric block cipher, meaning it uses the same secret key for both
encrypting and decrypting data. It processes data in fixed blocks of **128 bits** (16 bytes) using a substitution-permutation
network (SPN) structure.

Depending on the key size chosen, the algorithm performs a specific number of transformation rounds:

- **AES-128:** 10 rounds
- **AES-192:** 12 rounds
- **AES-256:** 14 rounds

---

### The Main Round Operations

Except for the final round, every standard round of AES consists of four distinct operational steps applied to the 4x4 matrix
of bytes (known as the _State_):

- **SubBytes:** A non-linear substitution step where each byte in the state is replaced with another using a lookup table
  (the **S-Box**). This provides confusion.
- **ShiftRows:** A transposition step where the rows of the state matrix are shifted cyclically to the left by different
  offsets (row 0 shifts by 0, row 1 by 1, row 2 by 2, and row 3 by 3). This provides diffusion.
- **MixColumns:** A linear mixing operation that combines the bytes in each column of the state matrix. _(Note: This step is
  skipped in the final round)._
- **AddRoundKey:** The current state is combined with a portion of the expanded round key using a bitwise **XOR** operation.

---

### Structure of an AES Encryption Process

1. **Initial Round:**

- `AddRoundKey` (using the initial secret key).

2. **Main Rounds:**

- Repeated for $N$ rounds ($10$, $12$, or $14$ times): `SubBytes` $\rightarrow$ `ShiftRows` $\rightarrow$ `MixColumns`
  $\rightarrow$ `AddRoundKey`.

3. **Final Round:**

- `SubBytes` $\rightarrow$ `ShiftRows` $\rightarrow$ `AddRoundKey` (skipping `MixColumns`).
