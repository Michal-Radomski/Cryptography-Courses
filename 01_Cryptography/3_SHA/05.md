## Overview of HMAC (Hash-based Message Authentication Code)

An **HMAC** is a specific type of cryptographic message authentication code involving a cryptographic hash function (like
SHA-256) and a secret cryptographic key.

While a standard hash (like SHA-256) tells you if a file or message has been modified, it doesn't prove _who_ sent it.
Because anyone can calculate a hash, an attacker could tamper with a message and generate a brand-new valid hash. An HMAC
solves this by requiring a **secret key** known only to the sender and the receiver.

---

### Core Purposes of HMAC

- **Data Integrity:** Ensures the message has not been altered in transit.
- **Authentication:** Verifies that the message genuinely came from someone who possesses the secret key.

---

### Implementing HMAC in Node.js

Node.js makes creating and verifying HMACs straightforward using the built-in `crypto` module. Here is a practical example:

```javascript
const crypto = require("crypto");

// 1. Define a secret key (keep this strictly confidential!)
const secretKey = "SuperSecretSharedKey123!";

const message = "Transfer $100 to Account B";
console.log("Original Message:", message);

// 2. Create an HMAC signature using SHA-256
function generateHmac(message, key) {
  return crypto.createHmac("sha256", key).update(message).digest("hex");
}

const signature = generateHmac(message, secretKey);
console.log("\nGenerated HMAC Signature:", signature);

// 3. Verify the HMAC signature (e.g., when received by a server)
function verifyHmac(message, key, receivedSignature) {
  const computedSignature = generateHmac(message, key);

  // Use timingSafeEqual to prevent timing attacks when comparing signatures
  const receivedBuffer = Buffer.from(receivedSignature, "hex");
  const computedBuffer = Buffer.from(computedSignature, "hex");

  if (receivedBuffer.length !== computedBuffer.length) {
    return false;
  }

  return crypto.timingSafeEqual(receivedBuffer, computedBuffer);
}

const isValid = verifyHmac(message, secretKey, signature);
console.log("\nSignature Valid?", isValid); // Returns true

// --- Example of Tampering ---
const tamperedMessage = "Transfer $10,000 to Account B";
const isTamperedValid = verifyHmac(tamperedMessage, secretKey, signature);
console.log("Tampered Message Signature Valid?", isTamperedValid); // Returns false
```

### Best Practices for HMAC:

- **Timing Attacks:** When comparing signatures in security-sensitive applications, always use `crypto.timingSafeEqual()`
  instead of standard operators (`===`) to prevent attackers from guessing signatures by measuring how long the comparison
  takes.
- **Key Security:** Just like symmetric encryption keys, the secret key used for HMAC must be securely stored and never
  exposed in client-side code.
