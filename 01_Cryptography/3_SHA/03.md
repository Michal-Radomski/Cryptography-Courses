## Password Hashing with Bcrypt and Argon2

While standard cryptographic hashes like SHA-256 are great for data integrity, they are far too fast for passwords. Modern
computers can compute billions of SHA-256 hashes per second, making them vulnerable to brute-force attacks.

Because of this, specialized **key derivation functions** like **Bcrypt** and **Argon2** are designed to be intentionally
slow and resource-intensive, making password cracking computationally expensive.

---

### 1. Bcrypt

Bcrypt is a classic, widely trusted password-hashing algorithm based on the Blowfish cipher. It automatically handles salting
behind the scenes and allows you to adjust a "work factor" (cost) to make it slower over time as computers get faster.

Here is how you use `bcrypt` in Node.js (requires running `npm install bcrypt`):

```javascript
const bcrypt = require("bcrypt");

const saltRounds = 12; // Controls how slow/secure the hashing is

async function hashPasswordBcrypt(password) {
  // Generates a salt and hashes the password automatically
  const hash = await bcrypt.hash(password, saltRounds);
  return hash;
}

async function verifyPasswordBcrypt(password, hash) {
  const match = await bcrypt.compare(password, hash);
  return match;
}

// --- Example Usage ---
(async () => {
  const password = "MySecurePassword123";
  const hashed = await hashPasswordBcrypt(password);
  console.log("Bcrypt Hash:", hashed);

  const isValid = await verifyPasswordBcrypt("MySecurePassword123", hashed);
  console.log("Bcrypt Verification Valid?", isValid); // Returns true
})();
```

---

### 2. Argon2

Argon2 is the winner of the 2015 Password Hashing Competition and is currently considered the gold standard for password
security. It provides resistance against both GPU-based cracking and side-channel attacks by consuming a configurable amount
of CPU time and memory.

Here is how you use `argon2` in Node.js (requires running `npm install argon2`):

```javascript
const argon2 = require("argon2");

async function hashPasswordArgon2(password) {
  // Automatically generates a secure salt and hashes using Argon2id
  const hash = await argon2.hash(password);
  return hash;
}

async function verifyPasswordArgon2(hash, password) {
  try {
    const match = await argon2.verify(hash, password);
    return match;
  } catch (err) {
    // Internal failure during verification
    return false;
  }
}

// --- Example Usage ---
(async () => {
  const password = "MySecurePassword123";
  const hashed = await hashPasswordArgon2(password);
  console.log("\nArgon2 Hash:", hashed);

  const isValid = await verifyPasswordArgon2(hashed, "MySecurePassword123");
  console.log("Argon2 Verification Valid?", isValid); // Returns true
})();
```

### Which One Should You Use?

- **Argon2** (specifically `argon2id`) is generally recommended for new applications because of its memory-hard design, which
  protects against powerful GPU and ASIC hardware crackers.
- **Bcrypt** remains an extremely reliable and robust industry standard if Argon2 dependencies cannot be easily installed in
  your deployment environment.
