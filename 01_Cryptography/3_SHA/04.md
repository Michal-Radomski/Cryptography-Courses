## Overview of the Blowfish Cipher

The **Blowfish** cipher is a symmetric-key block cipher designed in 1993 by Bruce Schneier as a fast, free alternative to
older encryption algorithms like DES.

---

### Key Characteristics

- **Block Size:** Blowfish operates on fixed blocks of **64 bits** (8 bytes). _(Note: This is smaller than AES's 128-bit
  block size)._
- **Variable Key Length:** It supports a flexible key size ranging from **32 bits up to 448 bits** (56 bytes), making it
  adaptable for different security requirements.
- **Feistel Network Structure:** It uses a 16-round Feistel network, meaning it processes data by splitting blocks in half
  and repeatedly swapping and modifying them through substitution and permutation functions.
- **Key-Dependent S-Boxes:** Blowfish generates its substitution boxes (S-boxes) dynamically based on the user's secret key
  during a pre-computation phase, making each key's operational structure unique.

---

### Current Status and Where It Is Used

While Blowfish was praised for its speed and high security at the time of its creation, it has largely been **superseded by
AES** in modern applications.

- **The Block Size Vulnerability:** Because its block size is only 64 bits, encrypting massive amounts of data under a single
  key makes it theoretically vulnerable to birthday attacks (such as the SWEET32 exploit), where an attacker can capture
  enough encrypted traffic to find patterns.
- **Where it survives:** While rare for bulk data encryption today, a modified variant of Blowfish forms the core foundation
  of **bcrypt**, the popular password-hashing function discussed earlier.
