## Hashing with Salt and Pepper

When storing user passwords in a database, simply hashing the password (like using SHA-256) isn't always enough. Attackers
can use precomputed tables of hashes (called rainbow tables) to crack them. To prevent this, developers use **salt** and
**pepper**.

---

### What Do They Mean?

- **Salt:** A random string of data added to each unique user's password before it is hashed. Because every user gets a
  different random salt, identical passwords (like `password123`) will produce completely different hashes in the database.
- **Pepper:** A secret string of data added to _every_ password across the entire system before hashing. Unlike a salt (which
  is stored in the database next to the user's hash), the pepper is kept strictly secret, usually stored safely in an
  environment variable or a dedicated secrets manager.

---

### Example Implementation in Node.js

Here is a practical example showing how to hash a password using a random salt and a system-wide pepper with Node.js's
built-in `crypto` module:

```javascript
const crypto = require("crypto");

// The system pepper (stored securely in environment variables in production)
const SYSTEM_PEPPER = "SuperSecretSystemPepperValue123!";

/**
 * Hashes a password using a salt and pepper
 * @param {string} password - The plain text password
 * @returns {Object} - The generated hash and salt
 */
function hashPasswordWithSaltAndPepper(password) {
  // 1. Generate a unique random salt for this specific user (16 bytes)
  const salt = crypto.randomBytes(16).toString("hex");

  // 2. Combine the password, salt, and system pepper
  const combinedData = password + salt + SYSTEM_PEPPER;

  // 3. Hash the combined string using SHA-256
  const hash = crypto.createHash("sha256").update(combinedData).digest("hex");

  return {
    salt: salt,
    hash: hash,
  };
}

// --- Example Usage ---

const userPassword = "MySecurePassword123";

// Simulate storing the user credentials in a database
const storedRecord = hashPasswordWithSaltAndPepper(userPassword);

console.log("Password:", userPassword);
console.log("Generated Salt (Stored in DB):", storedRecord.salt);
console.log("Generated Hash (Stored in DB):", storedRecord.hash);

// Later, when the user logs in, you verify by repeating the process with their stored salt:
function verifyLogin(inputPassword, storedSalt, expectedHash) {
  const combinedData = inputPassword + storedSalt + SYSTEM_PEPPER;
  const inputHash = crypto.createHash("sha256").update(combinedData).digest("hex");
  return inputHash === expectedHash;
}

const isLoginValid = verifyLogin("MySecurePassword123", storedRecord.salt, storedRecord.hash);
console.log("\nLogin Verification Successful?", isLoginValid); // Returns true
```
