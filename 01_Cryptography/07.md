## Generating Secure Random Numbers in Node.js

When dealing with cryptography, security tokens, or passwords, you should always use Node.js's built-in **CSPRNG**
(Cryptographically Secure Pseudo-Random Number Generator) via the `crypto` module, rather than standard math functions like
`Math.random()`.

Here is how you can generate random bytes, integers, and secure tokens:

```javascript
const crypto = require("crypto");

// 1. Generate random bytes (great for cryptographic salts or keys)
const randomBytes = crypto.randomBytes(16);
console.log("Random Bytes (Buffer):", randomBytes);
console.log("Random Bytes (Hex):", randomBytes.toString("hex"));

// 2. Generate a secure random URL-safe token (great for password resets or sessions)
const secureToken = crypto.randomBytes(32).toString("hex");
console.log("\nSecure Token:", secureToken);

// 3. Generate a cryptographically secure random integer within a range
// (e.g., between 1 and 100)
const randomInt = crypto.randomInt(1, 101);
console.log("\nSecure Random Integer (1-100):", randomInt);
```

### Why Use `crypto.randomBytes` instead of `Math.random()`?

- **`Math.random()`** is a standard PRNG designed for speed and simulations. It is mathematically predictable, meaning if
  someone knows enough previous outputs, they can guess future ones.
- **`crypto.randomBytes()`** taps into the operating system's secure entropy sources, making the generated numbers
  unpredictable and safe for security-critical tasks.
