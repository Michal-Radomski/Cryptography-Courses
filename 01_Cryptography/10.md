## How to Check If Secure Boot Is Enabled

Here is how you can quickly check the Secure Boot status on both Windows and Linux operating systems.

---

### On Windows

1. Press the **Windows Key + R** to open the Run dialog box.
2. Type `msinfo32` and press **Enter** to open the System Information window.
3. In the left-hand column, make sure **System Summary** is selected.
4. Look through the list on the right for **Secure Boot State**.

- If it says **On**, Secure Boot is active.
- If it says **Off**, it is disabled.
- If it says **Unsupported**, your motherboard or BIOS mode (Legacy instead of UEFI) does not support it.

---

### On Linux (Ubuntu and others)

You can easily check your system's Secure Boot status using the terminal:

1. Open your terminal.
2. Run the following command:

```bash
mokutil --sb-state

```

3. Look at the output:

- If it says **SecureBoot enabled**, it is active.
- If it says **SecureBoot disabled**, it is turned off.
- If it says `efi variables are not supported on this system`, your system might be booting in legacy BIOS mode rather than
  UEFI.
