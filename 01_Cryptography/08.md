## Overview of Root of Trust (RoT)

A **Root of Trust (RoT)** is a foundational set of functions, hardware, or software in a computer system that is trusted
implicitly by default. Because security has to start somewhere, the Root of Trust acts as the ultimate anchor for a device's
security architecture.

If the foundation is secure, everything built on top of it can be trusted. If the Root of Trust is compromised, the entire
system's security collapses.

---

### Key Components of a Root of Trust

A robust Root of Trust typically relies on a combination of hardware and software components:

- **Hardware-Based Security:** Often embedded directly into a computer's microchip or a dedicated secure crypto-processor
  (like a **TPM** or _Trusted Platform Module_ or Apple's Secure Enclave). Because it is built into hardware, it is much
  harder for hackers to tamper with than software alone.
- **Immutable Code:** The base code or firmware inside the Root of Trust is usually burned into read-only memory (ROM),
  meaning it cannot be modified, updated, or deleted maliciously.

---

### How It Works: The Chain of Trust

The Root of Trust is used to implement a **Chain of Trust** when a device boots up:

1. **The Starting Point:** When you turn on a device, the CPU executes the immutable code stored in the hardware Root of
   Trust.
2. **Step-by-Step Verification:** This trusted root checks and cryptographically verifies the signature of the next layer of
   software (like the bootloader) before loading it.
3. **Handing Off:** The bootloader then verifies the operating system kernel before starting it.
4. **Full System Integrity:** Each step verifies the next, ensuring that no malicious software has hijacked the system during
   startup (a process commonly known as **Secure Boot**).

---

### Where Is It Used?

- **Modern Smartphones:** To protect biometric data (like Face ID or fingerprint scans) and encryption keys.
- **Computers and Laptops:** To ensure the operating system hasn't been tampered with by malware before it loads.
- **IoT Devices & Servers:** To securely authenticate devices connecting to networks or cloud infrastructure.
