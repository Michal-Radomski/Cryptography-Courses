Homomorphic encryption is a specialized form of encryption that allows computations to be performed directly on ciphertext
without needing to decrypt it first. When the encrypted result is eventually decrypted, it matches the exact outcome that
would have occurred if the operations had been performed on the original plaintext.

### Core Types of Homomorphic Encryption

- **Partially Homomorphic Encryption (PHE):** Supports only a single type of mathematical operation—either addition or
  multiplication—an unlimited number of times. For example, RSA allows homomorphic multiplication.
- **Somewhat Homomorphic Encryption (SHE):** Supports both addition and multiplication, but only up to a limited circuit
  depth or number of operations before the "noise" in the ciphertexts corrupts the data.
- **Fully Homomorphic Encryption (FHE):** Supports an arbitrary number of both addition and multiplication operations,
  allowing complex, multi-layered computations (like running entire programs or algorithms) on encrypted data. First
  theoretically proven possible by Craig Gentry in 2009, modern FHE schemes have become vastly more efficient.

### Primary Applications

- **Privacy-Preserving Cloud Computing:** Allows organizations or individuals to outsource heavy data processing and storage
  to third-party cloud providers without revealing sensitive information (such as personal medical records or financial data)
  to the provider.
- **Secure Machine Learning:** Enables companies to train artificial intelligence models on encrypted user data or allow
  users to query AI models privately without exposing their inputs or queries.
- **Encrypted Database Queries:** Allows a server to search through or aggregate encrypted databases and return correct
  results to the user without ever knowing what data it is examining.
