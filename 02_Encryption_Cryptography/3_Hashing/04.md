A key derivation function (KDF) is a cryptographic algorithm that derives one or more secret keys from a primary secret—such
as a master secret, a password, or a passphrase—using a pseudorandom function.

KDFs serve two primary purposes in cryptography: stretching low-entropy inputs (like short human-readable passwords) into
high-entropy cryptographic keys, and safely expanding a single shared secret into multiple distinct keys for different
cryptographic operations.

### Core Functions of KDFs

- **Key Stretching (Password-Based):** When dealing with user passwords, KDFs like PBKDF2, scrypt, or Argon2 use salts and
  tunable computational costs to turn a weak password into a secure cryptographic key while frustrating brute-force attacks.
- **Key Expansion (Protocol-Based):** In protocols like TLS, a single master secret is established via key exchange. A KDF
  (such as HKDF) is then used to safely derive multiple independent session keys—such as separate keys for encryption,
  decryption, and message authentication—from that single master value.

### Common KDF Standards

- **HKDF (HMAC-based Extract-and-Expand Key Derivation Function):** Designed specifically for protocol engineers, HKDF
  follows an "extract-then-expand" paradigm. It first extracts a fixed-length pseudorandom key from input material and then
  expands it into any desired number of cryptographically strong output keys. It is heavily used in modern protocols like TLS
  1.3 and WireGuard.
- **PBKDF2:** A standard password-based KDF that applies a pseudorandom function (like HMAC-SHA-256) repeatedly with a salt
  and an iteration count to slow down computation.
