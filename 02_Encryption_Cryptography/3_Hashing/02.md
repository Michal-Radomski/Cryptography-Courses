A Merkle tree is a hierarchical cryptographic data structure used to efficiently and securely verify the integrity of large
amounts of data. Named after its inventor Ralph Merkle, it forms a foundational building block for blockchains, version
control systems like Git, and peer-to-peer networks like BitTorrent.

### How a Merkle Tree Works

Data is processed from the bottom up, forming a tree-like structure composed of three main layers:

- **Leaf Nodes:** The raw data (such as files, transactions, or data blocks) is split into chunks, and a cryptographic hash
  function (like SHA-256) is applied to each chunk to create the bottom row of hashes.
- **Parent/Branch Nodes:** Pairs of adjacent hashes from the row below are combined together and hashed again. This process
  repeats upward level by level.
- **Root Hash:** At the very top of the structure is a single hash value known as the **Merkle root**. This single string
  mathematically represents and summarizes every piece of data contained within the entire tree.

### Key Benefits

- **Efficient Verification:** Instead of downloading an entire dataset or checking every single file individually, a user can
  verify that a specific piece of data belongs to the set by checking a small subset of hashes known as a **Merkle proof**.
  This requires logarithmic time complexity ($O(\log n)$) rather than scanning everything.
- **Tamper Resistance:** Because every parent hash depends entirely on the blocks beneath it, changing even a single bit of
  data at the leaf level completely alters the Merkle root at the top. This makes unauthorized modifications instantly
  noticeable across the network.
