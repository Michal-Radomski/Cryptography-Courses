A bit-flipping attack is a type of cryptographic manipulation where an attacker modifies encrypted data (ciphertext) in
transit in a precise way to alter the resulting decrypted data (plaintext) without needing to know the secret encryption key.

This vulnerability typically occurs in encryption modes like Cipher Block Chaining (CBC) or vulnerable stream ciphers that
lack integrity protection, such as a Message Authentication Code (MAC). In CBC mode, because each ciphertext block depends on
the previous one, flipping a specific bit in a ciphertext block causes a predictable, matching bit flip in the decrypted
plaintext of the _subsequent_ block.

For example, if an encrypted message contains a user parameter like `is_admin=0`, an attacker who understands the data
structure can manipulate the ciphertext bytes. When the system decrypts the tampered data, the flipped bits change the
plaintext to `is_admin=1`, potentially granting unauthorized access.

To prevent bit-flipping attacks, systems use authenticated encryption modes—such as AES-GCM (Galois/Counter Mode)—which
include cryptographic integrity checks that instantly detect and reject any tampering with the ciphertext.
