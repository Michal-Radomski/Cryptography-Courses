A cold boot attack is a type of side-channel security exploit where an attacker with physical access to a computer can
retrieve sensitive data—such as encryption keys—from random-access memory (RAM) after the machine has been abruptly shut down
or rebooted.

Because RAM does not instantly clear its contents when power is lost, and the retention time increases significantly if the
memory chips are physically cooled (e.g., using compressed gas spray), an attacker can reboot the machine using a lightweight
operating system on a USB drive or physically remove the RAM sticks to read the residual data before it fades.

Modern systems mitigate cold boot attacks through hardware-based protections such as memory encryption, Trusted Platform
Modules (TPM), and features that automatically clear RAM contents upon unexpected reboots or removal.
