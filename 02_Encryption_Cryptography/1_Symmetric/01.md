AES in Electronic Codebook (ECB) mode is poor for encrypting images because it encrypts identical blocks of pixels into
identical blocks of ciphertext, which completely preserves the visual patterns, outlines, and shapes of the original image.

In ECB mode, each block of plaintext is encrypted independently using the same key. Images inherently contain large areas of
uniform color, repeating textures, and gradients. When these identical pixel blocks are processed through ECB, they result in
identical encrypted blocks. This failure to hide patterns allows anyone looking at the ciphertext to easily discern the
contours of the original picture—most famously demonstrated by the visible silhouette of the Linux penguin Tux when an image
of it is encrypted with ECB.

To properly secure an image, cryptographic modes that incorporate randomness and chaining—such as Cipher Block Chaining (CBC)
or Galois/Counter Mode (GCM)—must be used. These modes ensure that identical plaintext blocks result in completely different
ciphertext blocks, turning the image into unidentifiable noise.
